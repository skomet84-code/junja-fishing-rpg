# 준자 어드벤처: 통일 그래픽 1차 디자인 실험실

> 상태: 디자인 검증 중. **운영 브랜치에 미반영.** Render/Railway production, 게임 DB, 서버 규칙을 변경하지 않습니다.

## 1차 아트 기준
- 한국형 판타지 SD/2D 쿼터뷰, 따뜻한 왼쪽 위 광원, 통일된 부드러운 명암·굵은 윤곽.
- 모든 유닛은 투명 RGBA, 발바닥 기준(50%,100%) 앵커, 프로필과 필드가 같은 원화를 사용.
- 아이폰 390px 기준 전사 64×73px, 멧돼지 71×62px, 골렘 86×83px, 그림자 슬라임 72×75px.
- 별도 원화 시안: 전사 1종·몬스터 3종·마을/사냥터 참고 배경 2종.
- **독립 오프라인 HTML 시안은 별도 산출물**이며, 서버 인증·계정·DB와 연결하지 않습니다.

## 운영 투입 전 반드시 필요한 작업
1. 전사 4방향 또는 8방향 Idle/Walk/Attack/Skill 원화를 실제 프레임으로 작업.
2. 몬스터별 Idle/Walk/Hit/Death 애니메이션, 동일 화풍 및 바닥 기준점 고정.
3. PNG/WebP 투명도 디코딩·검은 네모·스프라이트 잘림 검사.
4. 실제 iOS Safari / 카카오 웹뷰 390px에서 캐릭터 크기와 성능 확인.
5. 실제 네트워크 이동 보정, 서버 충돌, 자동사냥/퀘스트와의 회귀 검증.
6. 승인 전까지 이 브랜치를 운영 railway-recovery로 **병합하지 않기**.

## 완료/미완료 구분
- 완료(시안 산출물): 캐릭터 및 몬스터 4개의 투명 PNG; 오프라인 조작·합성 미리보기; 크기 규격.
- 미완료: 정식 방향별 동작 원화, 게임 클라이언트 연결, 실기기 테스트, 운영 배포.

### 참고
이 리포지토리 브랜치에는 검증 규격만 기록합니다. 원화 PNG와 독립 HTML은 이 대화에서 전달하는 다운로드 자료에 들어 있습니다. 현재 운영 소스의 이미지는 교체하지 않습니다.
