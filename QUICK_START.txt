[준자의 낚시왕 RPG v0.2 - 빠른 시작]

1) Node.js 22 이상 설치
2) 이 압축파일을 원하는 폴더에 풀기
3) start_windows.bat 더블클릭
4) 브라우저에서 새 계정 생성
5) 플레이

같은 와이파이 친구와 플레이:
- 서버 PC에서 ipconfig 실행
- IPv4 주소 확인 (예: 192.168.0.15)
- 친구가 브라우저에서 http://192.168.0.15:3000 접속

인터넷 어디서나 접속하려면:
- 이 프로젝트를 공개 서버에 배포해야 함
- Dockerfile 포함
- data 폴더는 영구 디스크로 연결 권장

게임 데이터 초기화:
- 서버 종료 후 data/game.db 삭제

모바일 공개 링크:
- Render 등 공개 서버에 배포 후 https://주소 하나만 카톡으로 공유
- 게임 우측 상단 ↗️ 버튼으로 모바일 공유 메뉴 사용
- ⬇️ 버튼으로 홈 화면 설치 안내
