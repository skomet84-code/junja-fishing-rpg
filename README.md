# 🎣 준자의 낚시왕 RPG v0.2

브라우저에서 플레이하는 **모바일 우선 동시접속 온라인 낚시 RPG 플레이어블 빌드**입니다.

## 현재 구현된 기능

- 아이디 / 비밀번호 회원가입 및 로그인
- 비밀번호 `scrypt` 해시 저장, 7일 세션 쿠키
- SQLite 캐릭터 영구 저장
- 같은 낚시터 실시간 접속자 표시
- 실시간 자리 이동 / 채팅
- 4개 낚시 지역과 레벨 해금
- 16종 물고기, 6단계 희귀도
- 물고기 길이 / 무게 / 가치 랜덤 개체 생성
- CAST → 입질 → 챔질 → 줄 장력 → 랜딩 낚시 미니게임
- 낚싯대 5종 / 미끼 3종 / 상점 / 장착
- 경험치 / 레벨업 / 골드 / 가방 / 판매
- 영구 도감 및 최대어 기록
- 서버 전체 조사 랭킹
- 희귀·대물 실시간 낚시터 알림
- 모바일 전용 하단 내비게이션 및 터치 UI
- PWA 홈 화면 설치(Android/iPhone)
- Web Share API 기반 친구 초대 링크 공유
- PC / 모바일 반응형 UI
- 외부 npm 패키지 0개

## 가장 쉬운 실행 방법 — Windows

1. **Node.js 22 이상**을 설치합니다. (Node.js LTS 권장)
2. 압축을 풉니다.
3. `start_windows.bat`을 더블클릭합니다.
4. 브라우저에서 `http://localhost:3000`이 열립니다.
5. 새 계정을 만든 뒤 플레이합니다.

`npm install`은 필요 없습니다.

## 명령어로 실행

```bash
node server.js
```

그 다음 브라우저에서:

```text
http://localhost:3000
```

## 같은 와이파이에서 친구와 멀티하기

게임 서버를 켠 PC의 내부 IP를 확인합니다.

Windows:

```bat
ipconfig
```

`IPv4 주소`가 예를 들어 `192.168.0.15`라면 같은 공유기에 연결된 친구가 아래 주소로 접속합니다.

```text
http://192.168.0.15:3000
```

Windows 방화벽에서 Node.js의 사설 네트워크 접속 허용이 필요할 수 있습니다.

## 인터넷에서 누구나 접속하게 만들기

친구에게 `https://...` 주소 하나만 보내서 어디서든 접속하게 하려면 이 프로젝트를 **공개 서버에 배포**해야 합니다.

프로젝트에 `Dockerfile`이 포함되어 있으므로 Node/Docker 호스팅 서비스에 그대로 배포할 수 있습니다. 데이터 경로는 `DATA_DIR` 환경변수로 지정할 수 있습니다. 기본값은 `data/game.db`이며, Render 배포 예시는 `/var/data` Persistent Disk를 사용합니다.

운영 환경에서는 HTTPS를 반드시 사용하세요. HTTPS 프록시 환경에서는 로그인 쿠키에 Secure 속성이 자동 적용됩니다.

## 서버 구조

- `server.js` — HTTP API, 로그인, DB, 낚시 판정, SSE 실시간 멀티
- `public/index.html` — 게임 UI
- `public/style.css` — 게임 그래픽/UI 스타일
- `public/app.js` — 클라이언트 게임 로직, 월드 렌더링, 낚시 미니게임
- `data/game.db` — 최초 실행 시 자동 생성되는 SQLite DB

## 데이터 초기화

서버를 종료한 뒤 `data/game.db` 파일을 삭제하면 새 서버처럼 초기화됩니다.

## 프로토타입 보안 범위

비밀번호와 아이템/경험치/어획 데이터는 서버에서 관리합니다. 다만 v0.2의 낚시 미니게임은 브라우저가 계산한 플레이 점수를 서버가 검증하는 **기본형 구조**이므로, 상용 게임 수준의 치트 방지는 아직 아닙니다. 공개 서비스로 크게 운영할 때는 입력 샘플링·서버 시뮬레이션·속도 제한·감사 로그를 추가하는 것이 좋습니다.
