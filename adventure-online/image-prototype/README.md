# JUNJA ADVENTURE · ONLINE

공유 월드 온라인 버전 `20261006-online-2`입니다. 이전 단일 브라우저 전투 방식은 서버 권한 방식으로 교체했습니다.

- 계정을 만들고 캐릭터 4종 중 하나를 선택하세요. 캐릭터별 기록을 독립 저장합니다.
- 친구와 같은 채널 이름을 입력하면 함께 이동·채팅·사냥·보스 전투가 가능합니다. 채널당 24명입니다.
- 전사·도적·주술사·도사의 4개 스킬은 Lv.2/4/8/승급에 열립니다.
- Lv.10 및 왕꼬리 1회 처치 후 촌장에서 승급합니다. Lv.10부터 500 G로 직업을 바꿀 수 있습니다.
- 장비·가방의 사람 모양 장비창에서 투구·무기·갑옷·망토·신발·반지·귀걸이를 확인하고 착용합니다. 반지와 귀걸이는 능력치에만 반영합니다.
- 보스 참여자는 각자 희귀 장비 10%, 일반 장비 30%, 없음 60%로 독립 추첨합니다.
- 기존 이 브라우저의 v2 기록은 신규 가입 때 전사 캐릭터로 가져올 수 있습니다. 기존 플레이 주소에서 가입해야 해당 브라우저 기록을 찾을 수 있습니다.

## 실행·검증

Node 22+, `npm install --prefix server/online` 후 DATABASE_URL을 설정하고 `node server/online/server.mjs`를 실행하세요. 이미지 폴더만 정적 서버로 실행하면 온라인 API가 없으므로 접속할 수 없습니다.

`npm test --prefix image-prototype`는 핵심 로직 및 공유 전투/HTTP 검사를 실행합니다. PostgreSQL 재시작 저장 검사와 4명 동시 Chromium/WebKit UI 흐름은 GitHub Actions에서 실행합니다.
